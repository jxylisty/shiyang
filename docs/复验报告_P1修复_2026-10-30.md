### P1-1 横向溢出 — 通过

### P1-2 判定口径上屏 — 通过（前提：后端需运行新代码）
- /compounds/知母皂苷AIII 概率条下方渲染出完整一行：
  「判定口径：主模型概率 ≥ 0.7 为「高」，独立模型概率 ≥ 0.0837 为「高」（两模型概率尺度不同，独立模型阈值由其自身数据标定）。」
- 数值 0.7 与 0.0837 均来自后端字段 `cross_validation.main_threshold` / `.threshold`，屏上显示与 API 一致。

### P1-3 main_only 分歧文案 — 通过（前提：后端需运行新代码）
