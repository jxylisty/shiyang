## 二、分类要点

### A. 学术/研究系统

- **TCM-DS**（*Chin Med* 2025;20:191，DOI: 10.1186/s13020-025-01249-0）：澳门科大+华南理工+广医一院，DeepSeek R1 基座 + LoRA + RAG，症状→体质→可食用药膳方推荐，精确率 0.9924；论文 OA 但无面向公众的在线产品，无成分级药理证据链。
- **ShenNongDiet**（*Chin Med* 2026）：中国中医科学院，Neo4j 知识图谱（3,376 药膳/2,110 食材）+ Qwen3 稠密检索双通路 + LoRA「证据约束生成」，显式建模体质适宜性与配伍禁忌，Hit@5 92.67%。证据指「图谱引用与忠实度评估」，仍未下探到化学成分/靶点/通路层。
- **GitHub 开源**：KGR4TCM（KG 中医推荐）、ShenNongMi（1.9 万节点+NL2Cypher 导航）、膳时（九体质+二十四节气+现代营养标准，定位最近但无证据链）、PFoodReq（WSDM 2021 约束问答式食物推荐）、KG_Based_Recommendation_with_GNNs（128★）。均为研究原型，无入血/暴露量概念。

### B. 中文商业产品

- **知源中医**：中医学习工具（1 万+中药/1.6 万方剂/古籍/题库），纯查询，无测评驱动的推荐闭环。
- **小鹿中医**（阿里健康全资，互联网医院牌照）：分诊+问诊+购药；商业模式是医疗服务，不给用户自助食疗决策依据。
- **有方中医 / 茶养**：形态上最接近本项目——前者「AI 舌诊→辨体质→节气调理」，后者「体质问卷→按体质/功效/场景浏览茶方」，均免费上架。但推荐结果只有成品茶方/调理建议，**均无「成分→入血→靶点→通路」任何一层证据展示，也无数据来源字段**。
- **中医智库 / 大家中医**：面向学习与临床的古籍医案方剂库，医生侧工具为主。

### C. 国际对标

- **Examine.com**（加拿大，2011 年）：全球最大营养/补充剂循证数据库，5 万+文献，免费摘要 + 付费会员（据 Wayback 2025-12 存档确认免费层存在）；有最深的「成分→人体研究」证据体系，但**不做个性化推荐、无中医方剂语境、无药代动力学预测**，深度内容收费。
- **Yuka**（法国）：扫码评分（约 9,000 万用户），免费+Premium 订阅（离线扫描/历史记录付费，据存档页）；评分算法不完全公开；不做方剂与体质。
- **Open Food Facts**：开源众包成分库，全免费全透明，但只做「数据透明」，不做健康推理。

## 三、差异化定位结论

调研确认：**截至 2026 年，没有任何已核实产品同时具备「成分→入血概率→靶点→通路」的方剂级证据链展示**。本项目独有差异点：

1. **入血概率量化（PU-Learning）**——所有竞品的「证据」止于文献引用、图谱关系或研究分级；把「活性成分能否吸收入血」作为可计算的预测值展示，是全新维度（Examine 讲人体证据但不做预测；TCM-DS/ShenNongDiet 根本不进分子层）。
2. **方剂级成分暴露量估计（剂量×文献含量）**——竞品最多到「一杯茶含多少多糖」级别；把「喝这个方子大概摄入多少活性成分」与入血概率串联成可解释链路的产品为空白。
3. **证据链逐级可点开 + 数据溯源字段**——Yuka 算法不公开、知源中医仅标注来源、Examine 只给参考文献列表；本项目做到链条每一环（成分/靶点/通路/来源库）可点击、可回溯，透明度设计属首创组合。
4. **体质×场景双入口 + 全免费**——最接近的「茶养/有方中医」免费但无证据链；Examine 证据深但收费且无个性化推荐。本项目以大创身份把「CCMQ 九体质测评 + 场景 → 带完整证据链的方子」全免费开放，在中文市场形成独特卡位。

## 四、风险提示（答辩可主动讲）
