## 九、数据严谨性口径

1. 每条成分数据入库时保留 `source_db`（CTD/BindingDB/TCMSP 等）与 `reference` 字段——用户可见"数据来自哪"；
2. 成分暴露量为"剂量×文献含量"的**估计值**，方法学依据 EFSA 联合暴露指南（见《支撑论文清单.md》条目18），报告页明确标注；
3. 所有方子标注教材/文献出处，网方不采信；
4. 内容红线：全文使用"调理参考"，禁用"治疗/疗效"；页面固定免责声明。
