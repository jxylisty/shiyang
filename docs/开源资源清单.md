# 开源工具与数据资源清单

> 「食养有据」项目所用开源/公开资源一览（供开题汇报与结题材料引用）

## 一、权威目录与标准（产品合法性依据）

| 资源 | 内容 | 获取方式 |
|---|---|---|
| 按照传统既是食品又是中药材的物质目录 | 国家卫健委/市场监管总局四批公告（2002年87种 + 2019年6种 + 2023年9种 + 2024年4种 = **106种**） | [卫健委2024年公告](https://www.nhc.gov.cn/sps/c100088/202408/53150d0918ec40899b5293147ec0dd01.shtml)；已整理为 `data/food_homology_catalog.json` |
| 中医体质分类与判定（CCMQ量表） | 中华中医药学会标准（ZYYXH/T157-2009），60题/41题/30题版，九种体质转化分判定算法 | 标准文本公开，计分公式见量表说明 |

## 六、数据严谨性口径

1. 每条成分数据入库时保留 `source_db`（CTD/BindingDB/TCMSP等）与 `reference` 字段——用户可见"数据来自哪"；
2. 成分暴露量为"剂量×文献含量"的**估计值**，报告页明确标注；
3. 所有方子标注教材/文献出处，网方不采信；
4. 内容红线：全文使用"调理参考"，禁用"治疗/疗效"；页面固定免责声明。
