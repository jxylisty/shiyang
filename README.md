# 食养有据（shiyang）

> 药食同源食疗·茶饮有效成分分析平台 —— 基于「入血预测」大创课题成果的用户级产品

**一句话定位**：用户测体质/选场景 → 得到茶饮和食疗方推荐 → 每个方子都能点开一份"有效成分说明书"（活性成分 → 入血概率 → 作用靶点 → 通路富集 → 证据出处）。

与大创课题（`../my-asthma-system/`）的关系：本平台是**独立新产品**，转化复用大创课题的技术成果——PU-Learning 入血预测模型与分析管线。产品定位为全场景药食同源食养参考（护嗓/助眠/消化/护眼等），不绑定任何单一病种；三维机制评分维度沿用大创课题靶点富集框架，作为成分生物活性的一般性参考展示。

**数据规模口径（务必区分，2026-10-26 实测）**：
- 大创原始库（`../my-asthma-system/`）：278 味药材 / 569 化合物 / 7398 靶点——课题全量，本仓库不含；
- 本产品库（`data/shiyang.db`，2026-10 药材-成分归属重建后）：**34 味**（药食同源目录命中药材）/ **165 化合物** / **2807 人类蛋白靶点**（成分-靶点关联 12168 条）/ **73 方**（69 方有成分分析）/ **39 食物** / **9 体质**。
- 引用数字前先跑 `python -X utf8 scripts/check_overlap.py` 或直查库（AGENTS.md §6），**旧数字即刻作废**。

## 关键结论（2026-10 盘点）

- 药食同源目录 106 种中 **74 种（70%）已直接命中现有药材库**，关联 302 个去重化合物、其中 187 个高入血概率（prob≥0.5）→ 首批方子库可立即开建
- 未命中 32 种分两类：药材型（决明子/砂仁/灵芝/荷叶/莲子等，走 TCMSP 补成分）、食物型（赤小豆/黑芝麻/刀豆等，走新建 food 表 + 中国食物成分表营养素）
